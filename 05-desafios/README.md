# 05 — Desafios

Problemas para você resolver **sozinho(a)**, combinando tudo o que aprendeu na
unidade. Os enunciados dão menos dicas — planeje antes de programar:

1. Escreva o **algoritmo em português** (em comentários, no próprio arquivo).
2. Identifique as **entradas** (o que perguntar) e as **saídas** (o que mostrar).
3. Só então escreva o código e teste com **dados diferentes** do exemplo.
