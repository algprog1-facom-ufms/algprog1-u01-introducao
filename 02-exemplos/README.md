# 02 — Exemplos

Programas curtos e comentados. Para cada um:

1. **Leia** o código e tente imaginar a saída.
2. **Execute** no terminal, a partir da raiz do repositório:
   ```bash
   python 02-exemplos/ex01_ola_mundo.py
   ```
3. **Compare** com o que você imaginou.
4. **Altere** algo e execute de novo. Errar aqui não custa nada!

| Arquivo | Conceito |
|---|---|
| `ex01_ola_mundo.py` | Primeiro programa, `print` |
| `ex02_sequencia.py` | Execução sequencial |
| `ex03_print_varios_valores.py` | Vírgulas, `print()` vazio, `sep` e `end` |
| `ex04_caracteres_especiais.py` | `\n`, `\t`, aspas dentro de texto |
| `ex05_comentarios.py` | Cabeçalho e comentários |
| `ex06_input.py` | Entrada de dados com `input` |
| `ex07_cartao_de_visita.py` | Programa completo: entrada → saída |
| `ex08_erros_comuns.py` | Erros de sintaxe frequentes (para estudar, não para executar sem ler!) |
